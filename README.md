# Русский Рывок

Russian from the alphabet to A2. Daily ~10-minute sessions, all six cases, spaced repetition.
Open the app: https://papertowel2030-hub.github.io/russkiy-ryvok/

Progress is saved in your browser only. Pictures: OpenMoji (CC BY-SA 4.0). Fonts: PT Sans, PT Serif (SIL OFL).
Word frequency order: O. N. Lyashevskaya, S. A. Sharov, Частотный словарь современного русского языка (НКРЯ), 2009. Stress, meanings and word forms: OpenRussian.org dataset (CC BY-SA 4.0), cross-checked with OpenCorpora via pymorphy3.
